Pragmatic Workflow

Houdini, supercharged.

A production augmentation layer for Houdini. Workflow leaves Houdini's procedural core intact and augments the way you operate it: how much you can see, how quickly you can act, how deeply you can inspect, and how much technical context stays attached to the work.

The current major systems span parameter work, coding, graph comparison, viewport comparison, data-aware wires, cook activity, network connection tools, and overlay editing. Each system stays attached to Houdini's existing nodes, parameters, editors, and viewport rather than trying to replace the procedural core.

Parameter work

Advanced Parameter Workspace

A denser, more navigable way to inspect and edit Houdini nodes.

The workspace combines compact parameter layouts with search, node navigation, bookmarks, multiple-node editing, and integrated code editing. Everyday controls sit alongside expressions, references, animation channels, Motion FX actions, ramps, multiparms, and parameter-state feedback.

Search can target parameter names, labels, raw values, or evaluated values, with filters for non-default parameters, expressions, overrides, and time-dependent parameters. Editing still operates on the actual Houdini parameters rather than a separate parameter database.

Compact layouts Parameter search Bookmarks Node navigation Multiple-node editing Expression & animation state Ramps & multiparms Integrated code editing

Code editing

Monaco Editor / IDE

IDE-style editing with Houdini context attached to the code.

An integrated Monaco editing environment provides syntax highlighting, completion, function signatures, documentation, diagnostics, and definition navigation. It works with parameter-backed code, supported external source files, and code-to-parameter workflows.

Language intelligence is specialized by language: a dedicated VEX service, Pyright for Python and HOM, and clangd-backed C++/HDK and OpenCL analysis with Houdini-specific context where available.

VEX Python / HOM OpenCL C++ / HDK Completion Signatures Diagnostics Definition navigation

Monaco provides the editor surface. Workflow does not claim to embed the full VS Code product or its extension ecosystem.

Network change review

Graph Diff

See how a Houdini network was authored differently.

Graph Diff can expose nodes that were added, deleted, renamed, or modified, connection changes, parameter changes, expressions, animation channels, and differences between an unlocked asset and its saved definition.

Baselines can come from captured snapshots, saved snapshot files, another HIP scene, or a saved HDA definition. Changes appear directly in the network through annotations, connection differences, deleted-node ghosts, optional dimming, and an inspector for previous and current values.

Added / deleted nodes Renames & modifications Connection changes Parameter changes Snapshots HIP comparison Saved HDA comparison Code differences

Graph Diff compares authored network state. It is not a geometry diff, source-control system, automatic merge tool, or scene restore system.

Experimental · Viewport comparison

Viewport Compare

Compare two SOP results directly in the selected viewport.

Assign A and B sources, swap them, move or rotate the wipe, compare horizontally or vertically, stack both results, or isolate either source. Stacked views include modes such as Difference and Onion Skin for examining visible modeling, deformation, and procedural changes.

The comparison uses native viewport rendering integration and accounts for object transforms. Geometry objects resolve to their displayed SOP so the comparison stays focused on visible SOP results.

A / B sources Horizontal wipe Vertical wipe Rotatable wipe Stacked view Difference Onion Skin

Experimental. Difference modes compare rendered viewport colors, not point positions, topology, or numerical attribute values.

Data on the connections

Live Wires

Put useful graph data directly on the wires carrying it.

In SOP networks, wire labels can show added, removed, or touched attributes and volumes, point and primitive counts, memory differences, topology changes, time dependency, and available cook timing. Chain-end labels can summarize the resulting output.

Other Houdini contexts expose relevant metadata such as COP layers and types, CHOP channels and samples, LOP prims and layers, and DOP objects and simulation data. Labels can follow selections, related nodes, selected wires, or hovered connections.

Attribute changes Volume changes Point / primitive counts Memory differences Topology changes Cook timing COP / CHOP / LOP / DOP metadata

Live Wires uses bounded cached metadata and does not force cooks for label information. A touched attribute means cached identity or structure changed, not that every value was compared.

Observed cook activity

Cook Flow

See where Houdini is actively cooking, even during a synchronous cook.

Cook Flow highlights the active node and animates relevant network connections so ongoing computation is easier to locate. Wire effects, node effects, colors, animation speed, suppression delay, and completion bursts can be configured.

An independent renderer consumes idle-captured network snapshots and cook activity data, allowing the animation to continue while Houdini's main UI thread is occupied. Nested activity can be represented by the visible parent asset.

Active-node highlight Animated connections Independent renderer Delay threshold Completion bursts Nested activity

Cook Flow is an activity indicator, not percentage progress, data-packet visualization, or a replacement for profiling.

Network connection tools

Bezier Wires / Wire Enhancements

Change how connections read, focus, hide, reroute, and cut.

Bezier routing draws smooth curves between connectors with configurable curvature and smoother transitions through network dots. Straight and Rounded styles remain available, while appearance controls cover thickness, opacity, fading, and arrows.

Related wire tools include Branch Focus for dimming unrelated connections, connection hiding with endpoint indicators, rerouting gestures that insert aligned network dots, and configurable wire-cutting gestures.

Bezier routing Curvature control Thickness & opacity Arrows & fading Branch Focus Connection hiding Rerouting gestures Wire cutting

Bezier routing is a connection presentation system, not automatic obstacle avoidance or a global graph-layout solver. Native compatibility remains build and platform specific.

Graph + result in one workspace

Overlay Network Editor

Work on a real Houdini network editor while keeping the viewport result in context.

Overlay Network Editor places a usable Houdini network editor over the viewport. Adjust opacity, toggle visibility, temporarily hide it with a hold shortcut, switch between graph interaction and mouse pass-through, and fit the overlay to the active viewer.

The overlay hosts actual Houdini editor pane tabs rather than reimplementing the network editor, and it supports Network/APEX editor switching where applicable. Compatible Workflow network tools continue to operate inside that editor.

Real Houdini editor pane Viewport overlay Adjustable opacity Hold-to-hide Mouse pass-through Active-viewer fitting Network / APEX switching

The graph is visually overlaid on the viewport. Nodes are not placed in 3D space, and pass-through and graph interaction are separate input modes.

FAQ

Before you install.

Which Houdini versions and operating systems are supported?

Supported Houdini versions and operating systems will be published with the verified release before purchases open.

What is included with Workflow?

Workflow includes the shipping systems described in the main feature sections: High-Density Parameter Workspace, Context-Aware IDE, Pragmatic Node Info, Context-Aware Action System, Overlay Network Editor, Bezier Network Wires, Resource Monitor, Advanced Performance Profiler, C++ & HDK Development, and their supporting workflow tools. Graph Lenses, Visual Graph Diffing, Continuous Hierarchy Zoom / HDA X-Ray, Persistent Probes / Branch Experiments, Cook Gate / Freeze Region, and Reference Lens / Connect to Bookmark are labeled as in-development directions and are not current shipping claims. Pragmatic Operators is a separate product.

How does licensing work?

Individual licenses are assigned to one named customer, support one concurrent seat and up to two activated devices, and include 12 months of update coverage. Workflow is $199 Indie / $399 FX in year one, with $169 / $329 active renewal pricing. Eligible releases remain usable permanently. Studio licensing uses a floating concurrent seat pool sized to the purchased tier.

Can I customize the interface?

Yes. Verified options include density and layout, supported interaction preferences, overlay behavior, timeline interaction, Resource Monitor presentation, and other component-specific UI preferences. Available options vary by component.

How is Workflow different from Suite?

Workflow is the workspace and productivity product. Pragmatic Suite combines Workflow with Pragmatic Operators under the broader bundle offer. Operators is not included in a standalone Workflow license.
